## 📖 Описание проекта

**Skystore** — это веб-приложение на Django, представляющее собой каталог цифровых товаров (плагинов, утилит, ботов). Проект включает:

- Главную страницу с карточкой товара (демо)
- Страницу с контактами и формой обратной связи
- Подготовленную архитектуру для дальнейшего расширения: модели, маршруты, шаблоны с Bootstrap

Проект создан в учебных целях для изучения Django, GitFlow и Poetry.

## 🛠 Технологии

- **Python** 3.10+
- **Django** 4.2+
- **Poetry** — управление зависимостями и виртуальным окружением
- **Bootstrap 5** — стилизация через CDN
- **Git** + **GitFlow** — контроль версий
